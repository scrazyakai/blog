Docker基本命令

约 133 字小于 1 分钟

docker

2025-08-02

通俗的讲

镜像：相当于APP安装包

容器：安装的APP实例

查看版本

docker version

查看本机镜像

docker images

查看运行中的容器

docker ps

拉取镜像

docker pull 镜像名[:tag]

删除镜像

docker rmi 镜像ID

给镜像打标签

docker tag 源镜像ID 新名字:新tag
example: docker tag nginx:1.25 mynginx:prod

运行容器

复制编辑
docker run -d -p 8080:80 nginx
