    git常用命令

    Recursion2025/10/6小于 1 分钟杂谈git

    git命令

    初始化本地仓库

    git init

    将修改的所有代码提交到缓存区

    git add .

    提交缓存区

    git commit -m "***"

    推送提交

    git push

    查看当前状态（新增、修改、删除）

    git status

    切换分支

    git checkout <分支名>

    查看远程仓库

    git remote -v

    推送到远程仓库

    git push origin <分支名>

    安全回退推送

    git revert <commit_id>

    回退提交(保留修改在工作区)

    git reset --soft HEAD^
